Python Level 4 — Planet Visionara

Arah & Core Concept Pembelajaran

Siswa beralih dari aplikasi GUI prosedural menuju aplikasi desktop yang terstruktur dengan Object-Oriented Programming (OOP). Mereka memodelkan data menggunakan class dan object, membangun GUI berbasis class, mengatur navigasi multi-window, serta memecah program menjadi tiga modul Python (models, views, main).

Pertanyaan Utama Kelas: “Bagaimana kita merancang aplikasi manajemen yang rapi, mudah diuji, dan modular menggunakan object?”

Capaian Akhir Siswa

Siswa mampu merancang, membangun, menguji, dan mempresentasikan aplikasi manajemen berbasis OOP dengan struktur class yang terjelaskan secara utuh.

Produk Akhir Proyek

Aplikasi Banking, Library, Inventory, POS, atau solusi manajemen lain dengan tiga fitur MVP, GUI CustomTkinter, dan pemisahan model–view.

Bekal Prasyarat Level 3

Python dasar, list, function, condition, loop, CustomTkinter window/widgets, Entry, layout pack/grid, event command, dan traceback dasar.

Bukti Hasil Belajar

Prediksi kode, Bug Hunt, latihan terbimbing, mini-project, source code modular 3 file, hasil QA checklist, project blueprint, pitch, dan demo final.

Kesiapan Sebelum Level Dimulai

Siswa Sudah Mampu

  • Membuat dan menjalankan file .py di VS Code.
  • Menggunakan variable, list, condition, loop, dan function.
  • Membuat window, Label, Button, dan Entry di CustomTkinter.
  • Menggunakan pack()/grid() dan event command.
  • Membaca baris terakhir traceback error dasar.

Pengajar Sudah Menyiapkan

  • Python, VS Code, dan CustomTkinter teruji di laptop demo.
  • Deck dibuka pada Meeting dan section yang tepat.
  • File demo sebelum/sesudah perbaikan bug tersedia.
  • Screenshot expected output GUI tersedia.
  • Alternatif pair programming untuk perangkat terbatas.

Proyek Akhir · Pertemuan 9–12

Meeting 9 · Plan

Menemukan masalah pengguna, memilih ide, membatasi 3 fitur MVP, membuat class diagram, dan menyusun milestone.

Deliverable: Project Blueprint disetujui.

Meeting 10 · Build

Membangun window, widget, object data, dan alur GUI–model secara bertahap dengan checkpoint.

Deliverable: MVP/core mechanic berfungsi + pitch draft.

Meeting 11 · Test

Menghubungkan UI–backend, menjalankan test cases, memperbaiki bug, memoles UI, dan menyiapkan bukti demo.

Deliverable: Aplikasi presentation-ready + PPT 5–7 slide.

Meeting 12 · Showcase

Menjelaskan problem, target user, class model, atribut/method penting, object interaction, serta mendemonstrasikan fitur.

Deliverable: Presentasi, live demo/backup, Q&A, dan refleksi.
