1. Program Overview & Learning Journey

Level 3 merupakan jembatan emas bagi siswa dari pemrograman berbasis terminal hitam-putih (CLI) menuju pengembangan perangkat lunak nyata berantarmuka grafis (GUI). Siswa belajar bahwa tombol, kotak input, dan jendela aplikasi dibangun dengan kode terstruktur dan pola Event-Driven Programming.

2. Persiapan Teknis & Offline Contingency

A. Kebutuhan Perangkat Lunak

  • Python: Versi 3.10 atau lebih baru (Pastikan opsi Add Python to PATH dicentang saat instalasi).
  • Editor Kode: Visual Studio Code dengan ekstensi resmi Python (Microsoft).
  • Library GUI: customtkinter versi 5.2.0+.
# Perintah Instalasi Library di Terminal (Hanya 1x di awal level):
pip install customtkinter

# Verifikasi Berhasil:
python -c "import customtkinter as ctk; print(ctk.__version__)"

B. Protokol Keamanan & Anti-Crash Offline (Zero Secrets Guardrail)

Untuk memastikan proses belajar di kelas berjalan lancar tanpa kendala sinyal internet:

Skenario Risiko Dampak Jika Terjadi Solusi & Protokol Pengajar
Internet Sekolah Putus / Lambat Aplikasi tidak bisa fetch data eksternal (API) Gunakan MOCK DATA OFFLINE (Dictionary lokal) yang sudah disiapkan. Seluruh Core Mission berjalan 100% offline tanpa internet.
API Key Belum Aktif / Error Error HTTP 401 Unauthorized Jangan paksa siswa mendaftar API Key baru saat jam kelas. Arahkan menggunakan data simulasi lokal atau pilih Core Track (Converter/Login/To-Do).
Kebocoran Kredensial API Key pribadi disalin orang lain Dilarang keras menuliskan API Key pribadi pada slide/repo publik. Semua contoh di slide wajib memakai placeholder "{api_key}".

Misi 1: Intro to CustomTkinter & Root Window

🎯 Observable Learning Objectives:
Membuat jendela utama aplikasi (Root Window), mengatur judul, ukuran (geometry), dan tema warna Dark/Light mode.

1. Key Vocabulary & Istilah Teknis

Istilah Kunci: Root Window (jendela induk), geometry (lebar x tinggi pixel), appearance_mode (tema tampilan), mainloop (siklus hidup aplikasi).

2. Technical Brief & Arsitektur Kode

Event Loop (mainloop()): Jendela GUI tidak langsung menutup seperti script CLI karena berada di dalam infinite loop yang mendengarkan event OS (klik, gerak mouse). `app.mainloop()` wajib diletakkan di baris paling akhir.

3. Wireframe & Expected GUI Output

4. Common Misconceptions & Diagnostik Error Guru

Window langsung menutup sendiri: Guru memeriksa apakah baris `app.mainloop()` terlupa atau berada di dalam indentasi yang salah.

Misi 3: Entry Widgets (Form Input Pengguna)

🎯 Observable Learning Objectives:
Menerima input teks dari pengguna menggunakan CTkEntry dan membaca isinya dengan method .get().

Istilah Kunci: Entry (kotak input teks), placeholder_text (teks petunjuk abu-abu), .get() (menarik teks isian), show='*' (sensor sandi).

Misi 4: Layout Management (Pack vs Grid)

🎯 Observable Learning Objectives:

Istilah Kunci: Frame (wadah pengelompok), row (baris horizontal), column (kolom vertikal), sticky (penjajaran arah mata angin), padx/pady.

Misi 5: Event Handling & Functions in GUI

🎯 Observable Learning Objectives:
Menghubungkan klik tombol dengan fungsi Python melalui parameter command= dan memperbarui tampilan via .configure().

1. Key Vocabulary & Istilah Teknis

Istilah Kunci: Event (kejadian/klik), Callback (fungsi yang dipanggil sistem saat event terjadi), .configure() (mengubah properti widget saat runtime).

2. Technical Brief & Arsitektur Kode

Aturan Callback Tanpa Kurung: Parameter `command=nama_fungsi` menerima referensi objek fungsi, BUKAN hasil panggilannya. Menulis `command=nama_fungsi()` akan mengeksekusi fungsi di awal dan tombol menjadi mati.

Misi 6: Error Handling (Try & Except) in GUI

🎯 Observable Learning Objectives:
Melindungi aplikasi dari crash akibat kesalahan input user (huruf di kotak angka/form kosong) dengan try-except.

1. Key Vocabulary & Istilah Teknis

Istilah Kunci: Crash (aplikasi tertutup paksa), Exception (kondisi error saat runtime), ValueError (error ketidakcocokan tipe data), fallback.

2. Technical Brief & Arsitektur Kode

Robustness Standard: Aplikasi profesional tidak boleh crash di depan pengguna. Blok `try:` mencoba konversi `float()`, dan `except ValueError:` menangkap kegagalan untuk menampilkan pesan peringatan ramah.
