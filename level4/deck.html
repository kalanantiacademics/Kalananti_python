Tips & Do's / Don'ts

DO (Lakukan) ✅

Gunakan format PascalCase untuk nama Class. Setiap awalan kata pakai huruf kapital, tanpa spasi/underscore.


Contoh: MobilSport, RobotKalananti

DON'T (Jangan) ❌

Jangan gunakan format snake_case atau huruf kecil semua untuk nama Class.


Contoh Salah: mobil_sport, robot

Debugging Routine 🕵️‍♂️

Jika error saat membuat class atau objek, ikuti langkah ini:

  1. Cek titik dua : di akhir definisi class.
  2. Cek apakah indentasi (spasi menjorok) sudah benar.
  3. Pastikan memanggil class dengan huruf kapital yang sama persis.
  4. Pastikan pakai tanda kurung () saat membuat object! mobil1 = Mobil(), BUKAN mobil1 = Mobil.

Apa itu Attributes?

Attributes adalah variabel yang menempel pada sebuah Object. Mereka mewakili sifat atau karakteristik dari objek tersebut.

Contoh: Seekor kucing memiliki sifat: nama, warna, dan umur.

Apa itu Methods?

Methods adalah fungsi yang menempel pada sebuah Class. Mereka mewakili aksi atau kemampuan yang bisa dilakukan objek.

Contoh: Seekor kucing bisa melakukan aksi: makan(), tidur(), dan mengeong().

Code: Menggunakan `__init__`

Di Python, nama method constructor SELALU __init__ (dua underscore sebelum dan sesudah kata init).

class Kucing: # Constructor def __init__(self, nama_kucing, warna_kucing): # Memasang data ke dalam Atribut self.nama = nama_kucing self.warna = warna_kucing # Membuat objek dan langsung mengirim datanya kucing1 = Kucing("Milo", "Oren") kucing2 = Kucing("Luna", "Hitam") print(kucing1.nama) # Milo

Tips & Do's / Don'ts

DO (Lakukan) ✅

Gunakan format __init__(self, ...): dengan dua underscore (dunder). Dunder singkatan dari Double Underscore.

DON'T (Jangan) ❌

Jangan menulis _init_ (satu underscore). Fungsi tidak akan berjalan otomatis sebagai constructor.

Code: Kerangka Dasar OOP CustomTkinter

Kita akan mewarisi (inherit) kemampuan ctk.CTk ke dalam Class kita sendiri.

import customtkinter as ctk class AplikasiSaya(ctk.CTk): def __init__(self): super().__init__() # Memanggil constructor CTk self.title("Aplikasi OOP Pertama") self.geometry("400x300") # Simpan widget di self self.label = ctk.CTkLabel(self, text="Halo, OOP!") self.label.pack(pady=20) # Jalankan aplikasi if __name__ == "__main__": app = AplikasiSaya() app.mainloop()

Dengan super().__init__(), Class kita mendapatkan semua fungsi jendela CustomTkinter secara instan! self sekarang bertindak sebagai Jendela Utama (root).

Code: Menghubungkan Tombol

Bagaimana cara kita memasang command pada tombol?

class Aplikasi(ctk.CTk): def __init__(self): super().__init__() # command memanggil method menggunakan self self.btn = ctk.CTkButton(self, text="Klik Aku", command=self.saat_diklik) self.btn.pack(pady=20) # Ini adalah method-nya def saat_diklik(self): print("Tombol berhasil ditekan!")

Karena fungsi saat_diklik sekarang menempel pada objek self. Tanpa self., Python tidak akan menemukannya!

Apa itu Inheritance?

Inheritance (Pewarisan) memungkinkan kita membuat Class Baru berdasarkan Class yang sudah ada.

Class yang ditiru disebut Parent Class (Induk). Class yang baru disebut Child Class (Anak).

Sang anak akan secara otomatis mewarisi SEMUA atribut dan method sang induk tanpa kita harus mengetik ulang!

Method: maju(), rem()

Mobil (Child)

+ Atribut: roda = 4

↓ Mewarisi: maju(), rem()

Pesawat (Child)

+ Method: terbang()

↓ Mewarisi: maju(), rem()

Code: Sintaks Inheritance

Cara mewariskan class adalah dengan memasukkan nama Parent Class di dalam kurung setelah nama Child Class.

# Parent Class class Hewan: def makan(self): print("Nyam nyam!") # Child Class: Kucing (Mewarisi Hewan) class Kucing(Hewan): def mengeong(self): print("Meow!") kucing_oren = Kucing() kucing_oren.makan() # Method warisan dari Hewan kucing_oren.mengeong() # Method miliknya sendiri

Code: Memanggil super()

Saat kita butuh mengambil Constructor (__init__) milik parent, kita wajib menggunakan fungsi super().__init__().

class Karyawan: def __init__(self, nama): self.nama = nama class Programmer(Karyawan): def __init__(self, nama, bahasa_koding): super().__init__(nama) # Serahkan ke Parent self.bahasa = bahasa_koding # Khusus Child p = Programmer("Budi", "Python") print(p.nama, "ahli", p.bahasa)

class Bapak: def info(self): print("Ini dari Bapak") class Anak(Bapak): pass a = Anak() a.info()

Tips & Do's / Don'ts

DO (Lakukan) ✅

Gunakan konsep DRY (Don't Repeat Yourself). Jika dua class punya banyak atribut sama, buatkan Parent Class.

DON'T (Jangan) ❌

Lupa memanggil super().__init__() di dalam Child Class jika Child Class tersebut membuat method __init__ sendiri.

Solusi: Periksa apakah kamu lupa menulis super().__init__() di dalam Child! Tanpa perintah itu, Constructor Parent yang menyematkan atribut nama tidak pernah berjalan.

class JendelaPopup(ctk.CTkToplevel): def __init__(self, *args, **kwargs): super().__init__(*args, **kwargs) self.title("Jendela Tambahan") self.geometry("300x200") self.lbl = ctk.CTkLabel(self, text="Halo, saya Pop Up!") self.lbl.pack(pady=20)

  • Test 2: Klik tombol secara beruntun 10 kali cepat. Apakah aplikasi hang?
  • Test 3: Coba ganti halaman lalu kembali lagi. Apakah data sebelumnya hilang?

Struktur Presentasi (PPT)

Sambil menunggu teman yang belum selesai, siapkan slide presentasimu (Max 5-7 Slide):

  1. Slide 1: Judul & Perkenalan
  2. Slide 2: Masalah (Problem)
  3. Slide 3: Solusi (Demonstrasi Aplikasimu)
  4. Slide 4: Di balik layar (Tunjukkan 1 class OOP favoritmu)
  5. Slide 5: Tantangan yang dihadapi & Penutup
